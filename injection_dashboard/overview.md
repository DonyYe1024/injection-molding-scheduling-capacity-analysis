# 惠州注塑厂产能分析看板 · 交付说明

## 一、交付了什么

一个**单文件 HTML 数据可视化看板**（`index.html`，约 171KB），双击即可在浏览器打开（`file://` 下无跨域问题），无需安装、无需联网即可看核心数据（图表库需联网从 CDN 加载，无网时会有降级提示）。

看板完整解析了《最新排程产能分析-公式模板-最新.xlsm》（16 个工作表）的核心业务逻辑，覆盖：

| 模块 | 内容 | 数据来源 |
|------|------|----------|
| KPI 总览 | 总订单、扣库存后待生产、机台组数、原料种类、模具数、累计产值 | 综合 |
| 机台产能分析 | 5 组机台 × 53 周：实单工时 vs 产能工时 vs 预算工时 | 分析2-机台产能分析 |
| 模具产能分析 | 76 个模具实单工时 TOP 榜 + 模具×周热力图 | 原始数据1 |
| 原料分析 | 154 种原料 KG TOP 榜 + TOP5 周趋势 | 分析3-品种原料分析 |
| 产值分析 | 月度产值金额/数量 + 品类占比 | 原始数据5 |
| 备料明细汇总 | 品名/机台/周分布 | 原始数据1 |

## 二、关键业务规则（已内置到看板与上传重算）

- **工时公式**：`工时(小时) = 周期(秒) × 扣库存后待生产 ÷ 3600 ÷ 穴数`
- **机台分组**：`400T-550T` / `230T-260T`+`260T`→`230T-280T` / `150T` / `90T` / `0`→其他
- **模具编号**：从规格/品名按正则 `DH\d{3}[A-Z]?` 提取
- **周维度**：`2026WKxx` 格式，兼容数字/`WKxx`/`2026wk05`/带空格/Date 等多种写法

## 三、使用方法

1. **即开即用**：双击 `index.html`，直接看内置数据（已从当前备份文件抽取）。
2. **上传重算**：拖拽或点击上传新的 `.xlsx`，前端用 SheetJS 自动识别「工单备料明细」「外壳产值单价」两个表，实时重算机台/模具/备料/产值四模块（预算/原料保留内置值并在上传识别不到时提示）。
3. **恢复内置**：点「恢复内置数据」按钮回到初始状态。

## 四、文件清单

- `index.html` —— 看板（单文件，最终交付物）
- `data.json` —— 预抽取的聚合数据（125KB，已内嵌进 index.html，独立保留便于后续重新抽取）
- `_qa_check/` —— QA 校验脚本（可复跑）

## 五、v2 改善（2026-08-16）

### 改善1：机台产能图还原为「堆叠柱状图」
Excel 原档《分析2-机台产能分析》的 5 个机台组图表均为**堆叠柱状图**（实单工时 + 预算工时 两个系列堆叠，无产能线）。网页版已还原：每个机台组 Tab 的图改为「实单工时 + 预算工时」堆叠柱状（`stack:'total'`），删除原来的产能虚线与预算折线。

### 改善2：J~W 列公式搬进网页（自动计算）
因电脑性能问题，用户把《原始数据1》J~W 列公式算成纯数据。现已把全部公式逻辑搬到网页前端，并内嵌三张 VLOOKUP 映射表（产能参数 717 条 / 排程上线日期 4323 条 / BOM 1982 条）：

- **只需上传基础列 A~I（验货日期~可用库存）**，网页自动算出 J 工时、K 待生产累计、L 扣库存后待生产、M 上线日期、N 品种、O 注塑日期、P 周数、Q 机台、R 穴数、S 周期、T 毛重、U/V 原料、W 原料KG。
- 公式已用 300 行真实 Excel 数据逐行核对，与缓存值一致（含最复杂的扣库存 L 列）。
- 上传文件里某列**已有值则优先用**，缺失才用公式+映射补算。
- 计算为 O(n) 两遍扫描，2 万行约 144ms，不会卡顿。

### 映射表更新方式
三张映射表（产能参数/排程/BOM）相对稳定，已内嵌。新增模具或订单后，用 `_extract_mappings.py` 重新抽取映射、`_patch_mappings.py` 重新内嵌即可（注意：VLOOKUP 取「第一个匹配」，抽取脚本已用 `if code not in dict` 保留首个匹配）。

## 六、已知说明（非阻塞）

1. 上传重算后「预算工时」无数据来源（预算仅来自内置 DKL 预算表），上传后堆叠图中预算系列为 0，仅「实单工时」有效。
2. 内置数据含 `150T-280T` 合并组（分析表的派生汇总口径），上传重算按真实机台取值归为 4 组——正确行为，非 bug。
3. `90T` 机台组的预算工时在源 Excel 里公式报 `#VALUE!`，看板已做空值安全处理。
4. 映射表查不到的料号/订单号：相关列置空/0，机台归「其他」、周归「未排期」，不崩溃。
